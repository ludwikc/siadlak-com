# Architecture rules
- Scope MCT hub presentation through the shell's buyer variant and its dedicated stylesheet so course, briefing and enterprise pages retain their existing theme.
- Keep MCT text, prices, pathway definitions and enquiry rules in configuration modules; presentation changes must reuse these sources to avoid diverging offers.
- Keep Microsoft product logo references in one MCT configuration map backed by asset pointers so pathways and catalog tracks share the same product identity.
- Keep client logo identities and rendering variants in the MCT client configuration; store downloaded originals through asset pointers and preserve heraldic detail rather than flattening seals.
- Define client-band category membership in configuration independently of the legacy marquee groups; keep international and academic institutions outside national-government categories to avoid false affiliations.
